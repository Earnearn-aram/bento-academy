2.2 StreamingResponse

A normal response is built in full, then sent. A streaming response is sent piece by piece while your code is still producing it. In FastAPI you return a StreamingResponse that wraps a generator; each yield becomes one chunk on the wire…

Worked example

async def tokens():
    for t in ["Hel", "lo"]:
        yield t.encode()

@app.get("/demo")
async def demo():
    return StreamingResponse(tokens(), media_type="text/plain")
